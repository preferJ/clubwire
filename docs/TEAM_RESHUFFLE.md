# 팀 다시 섞기

`다시 섞기`는 해당 일정의 전체 참석 회원과 활성 게스트를 대상으로 팀을 새로 만든다.
기존 미리보기의 팀별 명단은 편성 입력으로 사용하지 않는다.

기존 `random_candidate_v1`은 난수가 달라도 전력 차이가 가장 작은 구성을 반복 선택할 수 있었다.
게스트도 입력 순서대로 배분해 같은 게스트끼리 계속 묶일 수 있었다.

`random_candidate_v2`에서는 회원과 게스트의 순서를 모두 무작위로 섞는다.
팀 수와 참석자가 직전 미리보기와 같으면, 전력 조건에 맞는 후보 중 직전과 다른 구성을 먼저 고른다.
팀 이름 교환과 명단 순서 변경은 같은 구성으로 취급한다. 이후 조합 다양성과 전력 균형의 기존 우선순위를 적용한다.

현재 후보에 전력 조건을 만족하는 다른 구성이 없으면 기존 구성이 다시 선택될 수 있다.
이때 응답의 `reshuffleChanged`가 `false`이며 화면에 재시도·전력 허용 차이 조정 안내를 표시한다.
첫 편성, 팀 수·참석자 변경, 재현용 `seed` 명시 요청에서는 이 값이 `null`이다.
명시한 seed는 기존처럼 같은 입력으로 같은 결과를 재현할 수 있다.

비교한 `previousGenerationId`와 변경 여부를 기존 편성 이력 JSON에 저장한다.
새 테이블이나 DB 마이그레이션은 필요하지 않다. 변경은 미리보기 단계에 적용되며 확정된 팀이나 경기 기록을 바꾸지 않는다.
