# 이달의 MVP 수동 선정

메인의 월간 MVP 후보 순위는 기존 포인트·동점 기준과 표시 방식을 유지합니다. 순위는 참고용이며, 실제 이달의 MVP와 발표 기사는 관리자가 선정할 때 만들어집니다. 월이 바뀌었다는 이유로 MVP를 자동 수여하지 않습니다.

## 관리자 사용 방법

1. 관리자 모드에서 **선수단 → 해당 선수**로 이동합니다.
2. **이달의 MVP선정**을 누릅니다.
3. 선정할 달을 선택합니다. 기본값은 한국 시간의 이번 달이며, 이전 달도 선택할 수 있습니다. 미래 달은 선택할 수 없습니다.
4. 선수를 MVP로 선정하면 수상 이력이 저장되고 발표 기사를 작성해 자동 게시합니다. 작성 중에는 상태를 확인할 수 있고, 게시가 끝나면 **MVP 기사 보기**로 이동할 수 있습니다.

이미 같은 선수가 그 달의 MVP이면 중복 선정하지 않습니다. 다른 선수가 선정되어 있으면 변경 확인 후 교체하며, 기존 수상과 기사는 이력으로 남깁니다. 삭제된 선수에게는 선정 버튼을 표시하지 않습니다.

기사 작성에 실패해도 선정된 MVP 기록은 유지합니다. 관리자 기사 화면에서 **다시 쓰기**로 기사를 재작성할 수 있습니다.

발표 기사는 특정 일정에 연결하지 않으며, 게시 후 메인 소식함과 기록의 **이달의 MVP** 기사 목록에 표시됩니다. 메인 소식함은 최신 게시 순으로 최대 3건을 표시합니다.

## API

클럽 접두사: `/api/clubs/{slug}`

두 API 모두 해당 클럽 관리자 인증이 필요합니다.

- `GET /monthly-mvp?month=YYYY-MM`: 해당 월 선정 상태
- `POST /members/{memberId}/monthly-mvp`: 관리자 선정. 본문은 `{ "month": "YYYY-MM", "replace": false }`입니다. 다른 수상자를 교체할 때 명시적으로 `replace: true`를 보냅니다.

선정 상태 응답에는 `month`, `winners`, `articleId`, `articleStatus`가 포함되고, 선정 응답에는 실제 변경 여부인 `changed`가 추가됩니다.
