# The Wire 기사거리(Insight) 목록 — 2026-10-20

유형 26종(기존 14종 + 2026-10-20 추가 12종). 연승·연속골은 프리뷰·마감 양쪽에 나와 표에 두 번 있음. 모두 구현됨.

## 공통 규칙

- 프리뷰: [일정확정] 때 생성. 그 일정 **이전** 확정 경기만 보고 판단
- 마감: [일정마감] 때 생성. 오늘 경기까지 포함
- 기사 1건에는 중요도 높은 순으로 최대 15개 사실만 전달(`WIRE_MAX_INSIGHTS`)
- 기준 숫자는 `INSIGHT_CONFIG_PARAM`에서 조정, 유형별 on/off·태그·중요도는 `INSIGHT_TYPE_CONFIG`
- Rating, 승리 예상 확률 같은 내부 숫자는 기사에 노출하지 않음
- 승률 = 승 ÷ 경기 수(무승부 포함)

| 징크스 조합 (JINX_PAIR / 징크스) | 같은 팀 배정 + 같은 팀 10경기 이상 + 승률 30% 이하. 하루 최대 2쌍 | ○○○·△△△, 징크스 깰까 |
| 득점왕 레이스 (SCORING_RACE / 레이스) | 이달 득점 1·2위 2골 차 이내 + 1위 3골 이상 + 둘 다 출전 | 9월 득점왕, ○○○·△△△ 1골 차 |
| 개근 (ATTENDANCE_STREAK / 개근) | 오늘 포함 6일정 이상 연속 출전 | ○○○, 11주 연속 개근 |
